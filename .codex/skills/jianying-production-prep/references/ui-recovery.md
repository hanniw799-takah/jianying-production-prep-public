# UI Recovery

Read this file only when a previously mapped Jianying path cannot be reused. Do not read it during a normal Production Prep run.

## Template or timeline not found

Confirm that the current project is the product project or the template copy designated by the user, not the original master template. Return to local drafts, locate the project by name, then take one complete state capture or screenshot to remap the cover timeline, four business timelines, cover compound clip, body slots, ending slots, and cover-copy slots.

## UI or template version changed

Use one complete accessibility snapshot plus one screenshot to remap the affected labels and text objects. Continue with differential state after the mapping is restored. Rely on the current UI rather than unrelated historical editing documentation.

## Paste timeout or unclear state

A Jianying paste timeout does not prove that the write failed. Select the object and inspect its text field or accessibility value first. Retry only if the value did not change. Commit multiline text by clicking another object rather than pressing Tab.

## Computer Use connection interrupted

Reacquire current state and bind the already-running Jianying window, then resume from the visible project. Reset the Computer Use session only if rebinding fails. After a reset, read the task Copy Pack and current UI state; do not reload unrelated historical files.
